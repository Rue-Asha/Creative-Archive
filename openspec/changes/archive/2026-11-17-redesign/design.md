## Goals / Non-Goals

**Goals:** S1–S20 of `scope.md`: shell and navigation (top bar, phone bar, context "+" and type sheet, worlds in the frame), every screen in the inventory (SC1–SC9, G1–G6) on the fingerprint with all contract states, Select mode with bulk status/tags in lists and move/remove in collections, drag and Move up/down reorder, magazines in the contract, the typed rating, the media initial status, the master icon, WCAG 2.2 AA and English copy, removal of the gate-1 adapters and of the old styling.

**Server (U3, used by U20 and U23)**
- `src/lib/server/bulk.ts`:
  - `bulkSetStatus(ids: Id[], status: Status): number` — one transaction; throws `ValidationError({ ids: 'Unknown entries: <ids>' })` when any id doesn't exist and `ValidationError({ status: 'Invalid status for <type>' })` when the status isn't valid for any selected entry's type, changing nothing; an empty list returns 0; entries already at that status are skipped (no event); media entries get a dated status event per change as `setStatus` does; returns the number changed.
  - `bulkTag(ids: Id[], name: string, op: 'add' | 'remove'): number` — one transaction; unknown id → `ValidationError({ ids })`; a blank name → `ValidationError({ tag: 'Tag is required' })`; `add` links the tag (created with the first spelling seen, same Unicode-aware key as `setEntryTags`) to every entry that lacks it; `remove` unlinks it and prunes unused tags; returns the number of entries changed; empty list → 0.
- `src/lib/server/collections.ts`: `removeManyFromCollection(collectionId: Id, entryIds: Id[]): number` — one transaction; any id that isn't a member → `ValidationError({ ids })`, nothing removed; the rest keep their relative order; touches the collection once.
- `src/routes/(app)/[domain]/[list]/+page.server.ts` actions: `bulkStatus` (form `ids` = comma-separated ids, `status`) and `bulkTag` (form `ids`, `tag`, `op` = `add` | `remove`) → `{ updated: number }` or `fail(400, { errors })`.

## Risks / Trade-offs

- [Transitional look between waves: old screens render with fingerprint roles over old tokens] → accepted; gate 6 is judged after the last build wave; e2e asserts behaviour, not visuals.
- [Baseline filter hides a regression in a not-yet-rebuilt file] → keyed by declaration text, so a new or changed declaration fails; Verify also runs bare `check-slop`; U24 removes the baseline.
- [Five pills + "+" don't fit at 320 px (R2)] → gate 4 shoots 320 px first; fallback icon-only pills with the names kept (settled 2026-11-16: icon-only below 360 px, fingerprint 2.0.0).
- [Dark worlds become light] → the fingerprint is light only and dark mode is a non-goal; Rue sees it first at gate 4/5.
- [Hi-fi units drift from the family] → the Frame owner (U8) runs before U10/U11, and every hi-fi brief carries "Family moves per surface".
- [Bulk write on many rows] → one transaction per action, all-or-nothing; 500 ids are well within SQLite limits; unit tests cover unknown ids and invalid statuses.
- [Reorder races between tabs] → 409 plus a reload with a polite toast; the client keeps the last saved order on any failure.
- [Old-look tests block the build] → reconciled once at 13.4; units migrate or retire them by name (P15).
- [Checkpoint A slips] → the build waits (group 13); gates 4–5 don't depend on it.
- [A primitive needs a change in a later wave] → the builder reports it, the orchestrator applies it between waves; fingerprint changes go to Design-System `requests.md`.
